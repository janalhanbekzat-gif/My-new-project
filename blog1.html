Веб-әзірлеуді үйрену тәжірибем

23 Қараша, 2026

Веб-әзірлеуді үйрену барысында мен HTML, CSS және JavaScript технологияларын меңгере бастадым. Алғашында қиын болғанымен, тәжірибе арқылы бәрі түсінікті бола түсті.

Үйренген технологиялар

  • HTML5 семантикалық тегтері
  • CSS негіздері
  • Flexbox Layout
  • Git және GitHub

Мақсаттарым

Болашақта үлкен жобаларда жұмыс істеп, сенімді және қауіпсіз веб-қосымшалар жасағым келеді.
